# UGN GTA VI Guide — Search discovery and organic launch

Live site: https://universal-gaming.github.io/GTA-6-Guide/

## First: get indexed

1. Open [Google Search Console](https://search.google.com/search-console) and add the URL-prefix property `https://universal-gaming.github.io/GTA-6-Guide/` (not the entire github.io domain unless you control it).
2. Complete Google's ownership verification using the method offered for your GitHub Pages property. **Do not put secret tokens or credentials in this repository.** A public HTML verification file or DNS method may be supported depending on your property and account.
3. Submit `https://universal-gaming.github.io/GTA-6-Guide/sitemap.xml` in the Sitemaps section.
4. Use URL Inspection to request indexing for the homepage, [Leonida map](https://universal-gaming.github.io/GTA-6-Guide/leonida-map.html), [FAQ](https://universal-gaming.github.io/GTA-6-Guide/discover.html), [locations](https://universal-gaming.github.io/GTA-6-Guide/locations.html) and [mission guide](https://universal-gaming.github.io/GTA-6-Guide/missions.html). Requests do not guarantee indexing.
5. Open [Bing Webmaster Tools](https://www.bing.com/webmasters/), import the verified Search Console property where supported, or verify separately; submit the same sitemap.
6. In both tools, monitor *indexed pages*, *crawl errors*, *queries*, *impressions* and *clicks* weekly. Fix discovered issues before adding more content.

## Content and trust checklist

- Each page answers a real question with original, sourced, useful details, rather than keyword stuffing.
- Link directly to the relevant guide section, not always the homepage.
- Update dated/uncertain facts and mark unverified locations clearly.
- Keep page titles, meta descriptions, canonical URLs, sitemap and mobile navigation accurate.
- Avoid claiming the 95-entry legacy mission tracker is the complete canonical story.
- Keep Rockstar and Take-Two non-affiliation visible.
- Verify third-party poster hosting remains available; a broken image makes the primary landing page less useful.

## What this does not do

This repository cannot verify your Google/Bing ownership or submit Search Console properties on your behalf without your authorization. Structured data does not guarantee enhanced search appearance. Search engines choose if and when to crawl, index and rank pages. No traffic numbers are guaranteed.
